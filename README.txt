# UDAAN — Student + Subject Teacher Portal

**UDAAN** is a web-based student and subject teacher portal designed to provide a simple interface for accessing student information, filtering classes, viewing student details, and demonstrating an early-warning system based on assessment history.

The project is a **frontend prototype** built using HTML, CSS, and JavaScript.

## ✨ Features

### 🎓 Student Dashboard

* Interactive student dashboard.
* Displays sample student data.
* Simple and user-friendly interface.
* JavaScript-powered dashboard interactions.

### 👩‍🏫 Subject Teacher Portal

* Dedicated portal for subject teachers.
* Class filtering functionality.
* Student details viewing.
* Demonstration of an early-warning system using sample assessment history.

## 🛠️ Technology Stack

* **HTML5** — Structure of the web pages.
* **CSS3** — Styling and responsive layout.
* **JavaScript** — Interactions, class filtering, and demo functionality.
* **Visual Studio Code** — Development environment.
* **Live Server** — Local development and preview.

## 🚀 Getting Started

### Prerequisites

Install the following:

* [Visual Studio Code](https://code.visualstudio.com/)
* [Live Server Extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)

### Installation and Setup

1. Download or clone this repository.
2. Extract the ZIP file if you downloaded the project as a ZIP.
3. Open the project folder in Visual Studio Code.
4. Install the Live Server extension if it is not already installed.
5. Open `index.html`.
6. Right-click inside the editor and select **Open with Live Server**.

The student dashboard will open in your default browser.

### Open the Subject Teacher Portal

1. Open `subject_teacher.html` in Visual Studio Code.
2. Right-click inside the editor.
3. Select **Open with Live Server**.

The subject teacher portal will open in your browser.

## ⚙️ How It Works

**Student Portal:** Displays a student-facing dashboard with interactive elements powered by JavaScript and demonstration data.

**Subject Teacher Portal:** Provides class filtering, student detail views, and an early-warning demonstration based on assessment history.

Both portals currently operate independently using frontend sample data.

## ⚠️ Current Limitations

This version is a frontend prototype and has the following limitations:

* No shared database.
* No real user authentication or role-based access control.
* No live synchronization between the student and teacher portals.
* Student information and assessment history are demonstration data.
* The early-warning feature is not connected to real assessment records.

**Important:** The early-warning feature should not be used to make actual decisions about students until it has been validated and connected to reliable assessment data.

## 🎯 Project Goal

UDAAN aims to demonstrate how a digital portal can support student engagement, teacher access to academic information, and the early identification of students who may need additional academic support.
