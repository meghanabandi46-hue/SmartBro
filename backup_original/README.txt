UDAAN — Student + Subject Teacher Portal

FILES
- index.html: Student dashboard
- style.css: Student dashboard styling
- script.js: Student dashboard interactions/demo data
- subject_teacher.html: Subject Teacher Portal
- subject_teacher.css: Teacher portal styling
- subject_teacher.js: Teacher portal interactions, class filter, student details, early warning demo

RUN IN VS CODE
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click index.html and choose Open with Live Server to open the student portal.
5. To open the teacher portal, open subject_teacher.html with Live Server.

IMPORTANT
This is a frontend prototype using sample data. It does not yet have a shared database, real authentication, or live syncing between student and teacher portals. The early-warning feature uses demonstration assessment history; connect it to real assessment records before using it for actual student decisions.
